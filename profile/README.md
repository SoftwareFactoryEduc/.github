# Software Factory Educ

Resolvemos problemas reais de escolas com software feito sob medida, rápido.

**Como trabalhamos**
1. **Diagnóstico**: sentamos com a escola e entendemos o problema de verdade.
2. **Escopo**: definimos a menor solução que resolve, com prazo curto.
3. **Mão na massa**: construímos, testamos com quem vai usar e entregamos.
4. **Acompanhamento**: ajustamos com base no uso real.

Quer conversar? Abra uma discussão ou fale com a gente.
